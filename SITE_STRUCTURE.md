## Dashboard Card Template

```html
<article class="dashboard-card">
    <div class="card-header">
        <h3>EMOJI Title</h3>
        <p>One-line description</p>
    </div>
    <div class="card-actions">
        <a href="reports/<slug>/index.html" class="btn btn-primary">Launch Dashboard</a>
    </div>
</article>
```

Button text variants: `Launch Dashboard` / `View Reports` / `View Digest`

---

## Adding a New Report — Checklist

1. `git pull` first (prevents index.html merge conflicts)
2. Create `reports/<slug>/` and put output file(s) inside
3. Add `<article class="dashboard-card">` to the correct section in `index.html`
4. If it's an **earnings tearsheet**: run `python3 scripts/generate_earnings_index.py` after copying the `.md` file to `reports/earnings/`
5. `git add` → `git commit` → `git pull --rebase` → `git push`

---

## Key Generator Scripts

| Script | Output |
|--------|--------|
| `scripts/generate_earnings_index.py` | Rebuilds `reports/earnings/index.html` from all `.md` files |
| `scripts/generate_index.py` | Rebuilds `index.html` (use with caution — manual edits may conflict) |
| `scripts/generate_<slug>.py` | One-off generators per dashboard |

---

## Earnings Tearsheets

- Files: `reports/earnings/<TICKER>-<YYYY-MM-DD>.md`
- Index auto-generated by `generate_earnings_index.py`
- **Never manually edit** `reports/earnings/index.html`

## Sovereign Notes

- Files: `reports/sovereign/<country>-<YYYY-MM-DD>.md`
- Published by the `tools:em-sovereign-credit-note` skill

B + C exceeds 100% — reduce one input.
Terminal-rate anchors are fixed assumptions: A = 3.00%, B = 4.50%, C = 5.625% (midpoint of 150–175bp of hiking). Implied rate for a given (A,B,C) mix = 3.00·A + 4.50·B + 5.625·C. Market rate = 100 − SFRZ7 price. Diff = implied − market, in basis points. This is a static probability-weighted read, not a forward path — it does not account for convexity, carry, or the Z7/Z8 term slope.

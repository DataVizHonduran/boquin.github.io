Methodology & Caveats

Data source: OpenSky Network API (/api/flights/arrival and /api/flights/departure). Flights are counted per calendar day (UTC) per airport by ICAO code. Each daily count reflects the sum of arrivals and departures as recorded in the OpenSky database, which aggregates ADS-B and MLAT data from a global network of receivers. Data is batch-processed overnight; only dates up to yesterday are fetched.

Airport scope: Only the 10 airports in neighboring countries are tracked. Iranian airports are excluded because ADS-B ground receiver coverage inside Iran is too sparse to produce meaningful counts.

Pre-conflict baseline: Average daily total flights in all cached dates before 2025-10-01. The % vs. baseline metric compares the most recent 7-day rolling average against this baseline.

Cache: Historical data is cached in reports/iran-flight-monitor/data/cache.json. Only missing dates are fetched on each run to minimize API usage. Fetch windows are up to 7 days per request per direction per airport.

Attribution: Flight data provided by The OpenSky Network, Matthias Schäfer, Martin Strohmeier, Vincent Lenders, Ivan Martinovic and Matthias Wilhelm. "Bringing Up OpenSky: A Large-scale ADS-B Sensor Network for Research." IPSN 2014.

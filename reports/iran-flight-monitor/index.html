Methodology & Caveats

Data source: FlightRadar24 API v1 (/api/v1/flights/summary/light). Flights are counted per calendar day (UTC) per airport by IATA code. Each daily count reflects the sum of arrivals (destination = airport) and departures (origin = airport) as reported in the FR24 database.

Pre-conflict baseline: Average daily total flights in all cached dates before 2025-10-01. The % vs. baseline metric compares the most recent 7-day rolling average against this baseline.

Coverage caveat: Iran restricts ADS-B transponder broadcasts; FlightRadar24 relies on ground receiver networks which have limited coverage inside Iranian airspace. Counts reflect tracked flights only and may significantly undercount actual military, cargo, or short-haul domestic traffic.

Cache: Historical data is cached in reports/iran-flight-monitor/data/cache.json. Only missing dates are fetched on each run to minimize API usage.

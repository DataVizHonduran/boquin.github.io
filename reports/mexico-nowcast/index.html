Mexico GDP Nowcaster

Real-time estimate of Mexico IGAE/GDP growth — updated monthly as new data arrives

How the nowcast works

Mexico's IGAE (Indicador Global de la Actividad Económica) is INEGI's monthly proxy for GDP, published with a ~45-day lag. This nowcaster bridges that gap using three OLS bridge equations fitted on quarterly data since 2016:

  • Activity bridge — IMEF Manufacturing and Non-Manufacturing PMI (3-month moving averages), capturing domestic business-cycle momentum.
  • External bridge — US Industrial Production YoY, WTI crude oil YoY, and US manufacturing employment YoY, reflecting the tight Mexico–US trade linkage.
  • Financial bridge — USD/MXN YoY and IPC Bolsa Mexicana YoY, incorporating real-time financial-market signals.

Each bridge is validated with an expanding-window out-of-sample test (train from 2016, evaluate 2018–2023). Bridges are combined using inverse-RMSE ensemble weights — better-fitting bridges receive higher weight. The current-quarter estimate (red star, plotted at today’s date) uses only the months of data available so far — it updates each month as new data arrives. The 90% confidence interval comes from 1,000 residual bootstrap iterations. Because the quarter is still in progress, treat the estimate as directional rather than precise.
